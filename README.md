# HelmetShop – Manual Testing Portfolio

> **Role:** Manual Tester / QA Intern Project  
> **Project type:** E-commerce website  
> **Testing focus:** Functional, UI, Negative, API, Database, Retest & Regression

## 1. Project Overview

HelmetShop is an e-commerce website for selling helmets. Customers can browse products, view product details, manage a shopping cart and place orders. Admins can log in, manage products and manage customer orders.

This repository documents the **Manual Testing process** performed for the project.

## 2. My QA Activities

- Requirement analysis
- Test scope definition
- Test scenario design
- Test case design
- Test data preparation
- Functional testing
- UI testing
- Responsive testing
- Positive & negative testing
- Equivalence Partitioning (EP)
- Boundary Value Analysis (BVA)
- Decision Table testing
- State Transition testing
- REST API testing with Postman
- Database validation with PostgreSQL / DBeaver
- Bug reporting and tracking
- Retesting
- Regression testing
- Test summary reporting
