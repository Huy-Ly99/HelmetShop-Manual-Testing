# Portfolio Working Rules

1. Record only tests that were actually executed.
2. Never invent PASS/FAIL counts.
3. Do not commit passwords, JWT secrets, API keys, database credentials, or real customer data.
4. Replace sensitive data with placeholders.
5. Keep screenshots/videos focused on the defect or test evidence.
6. Use clear Test Case and Bug IDs.
7. Update Retest and Regression results after fixes.
